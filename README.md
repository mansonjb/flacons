# Flacons — bar à vin, La Rochelle

Site vitrine one-page du bar à vin **Flacons**, 8 rue de la Ferté, 17000 La Rochelle.

- `index.html` — la page (HTML statique, styles inline issus de la maquette Claude Design, polices Google Fonts)
- `map.html` — plan Leaflet + tuiles OpenStreetMap, chargé en iframe dans la section « Horaires & accès »
- `img/` — photos et visuels

Publié via GitHub Pages depuis la branche `main` (racine du dépôt).
